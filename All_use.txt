==================================================
🔥 Git + 폴더/파일 관리 + 작업 흐름 올인원 치트시트
==================================================

[0] 로컬 폴더/파일 기본 작업 (운영체제 명령어)
----------------------------------------------

# 폴더 생성
mkdir 폴더명

# 폴더 이동
cd 폴더명

# 파일 생성 (빈 파일)
touch 파일명.txt

# 파일 삭제
rm 파일명.txt              # Mac / Linux
del 파일명.txt             # Windows

# 폴더 삭제
rm -r 폴더명               # Mac / Linux
rmdir /s 폴더명            # Windows

# 파일 목록 보기
ls                         # Mac / Linux
dir                        # Windows

# 빈 폴더를 Git에서 추적시키는 방법 (.gitkeep 사용)
mkdir 폴더명
touch 폴더명/.gitkeep


[1] Git 저장소 초기화 및 연결
-------------------------------
git init
git remote add origin https://github.com/사용자/저장소명.git
git remote -v


[2] 변경 상태 확인 (항상 자주 쓰는 명령어)
----------------------------------------
git status           # 수정된 파일 확인
git diff             # 수정된 내용 비교
git log --oneline    # 커밋 히스토리 간단하게 보기


[3] 파일 1개만 수정/추적/커밋/푸시
----------------------------------
git add 파일명
git commit -m 
파일
수정
내용
git push origin 브랜치이름


[4] 전체 변경사항 스테이지 → 커밋 → 푸시
-----------------------------------------
git add .
git commit -m 전체
변경사항
커밋
git push origin 브랜치이름

# 강제 푸시 (⚠ 매우 주의)
git push origin main --force


[5] 원격 저장소 내용 가져오기
-------------------------------
git pull origin 브랜치이름
# 예: git pull origin main


[6] 로컬 변경 다 버리고, 원격 내용으로 완전 덮어쓰기 (⚠ 위험)
----------------------------------------------------------
git fetch origin
git reset --hard origin/브랜치이름
# 예: git reset --hard origin/main


[7] 원격에서 특정 파일만 가져오기 (중요)
-----------------------------------------
git checkout origin/브랜치이름 -- 파일경로/파일명
# 예: git checkout origin/main -- src/App.js


[8] 파일 삭제하고 반영
----------------------
git rm 파일명
git commit -m 파일
삭제
git push origin 브랜치이름


[9] 커밋하지 않은 수정/새 파일 삭제하기 (⚠ 복구 어려움)
-------------------------------------------------------
# 수정되었지만 커밋되지 않은 파일 되돌리기
git restore 파일명

# 추적되지 않은 새 파일 삭제
git clean -f

# 폴더 포함 삭제
git clean -fd

# 삭제될 목록 미리 보기 (안전)
git clean -n


[10] 폴더/파일 이동 또는 이름 변경 (Git 반영 포함)
---------------------------------------------------
# Git 기본 이동 명령 (OS mv 와 git add -A 보다 안전)
git mv 기존이름 새이름
git commit -m 이름
변경


[11] 브랜치 작업
-----------------
git branch                      # 브랜치 목록
git checkout 브랜치명           # 브랜치 이동
git checkout -b 새브랜치명      # 브랜치 생성 + 이동
git push origin 브랜치명        # 원격에 브랜치 올리기
git branch -d 브랜치명          # 브랜치 삭제


[12] 브랜치 병합 (Merge)
-------------------------
git checkout main
git merge 작업브랜치명

# 충돌 발생 시 → 파일 수정 → 저장 → 아래 실행
git add .
git commit


[13] 최근 커밋 메시지 수정
-------------------------
git commit --amend


[14] 실수한 커밋 되돌리기 (안전한 방식)
----------------------------------------
git revert 커밋ID
git push origin 브랜치명


[15] .gitignore 설정 (추적에서 제외할 파일)
-------------------------------------------
touch .gitignore

# 예시 내용
node_modules/
*.log
.env
.vscode/


==================================================
✅ 핵심 요약
==================================================
- **폴더 생성은 Git 명령이 아니라 OS 명령으로 함**
- **Git은 빈 폴더를 추적하지 않음 → .gitkeep 파일 넣어서 처리**
- **파일 하나만 올리면 → git add 파일명**
- **전체 변경 올릴 땐 → git add .**
- **reset --hard / clean -f / --force 는 데이터 날아가니 신중하게**
